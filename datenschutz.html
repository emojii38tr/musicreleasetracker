2. Zweck der App

Die App „Music Release Tracker“ zeigt neue Musikveröffentlichungen an und ermöglicht das Markieren von Favoriten. Optional können Push-Benachrichtigungen zu Neuigkeiten empfangen werden.

3. Verarbeitete Daten in der App

  • Favoriten: lokal auf dem Gerät gespeichert (keine Serverübertragung).
  • Netzwerkzugriffe: Abfragen der Spotify Web API (Künstler-, Albumdaten, Coverbilder).
  • Bilder: Cover werden per URL geladen (Coil/HTTP), es werden keine Bilder dauerhaft serverseitig gespeichert.

4. Firebase Cloud Messaging (FCM)

Für Push-Benachrichtigungen verwendet die App „Firebase Cloud Messaging“ (Google). Dabei wird ein Geräte-Token erzeugt. Dieses Token kann genutzt werden, um Nachrichten gezielt an das Gerät zu senden. Das Token wird nur zur Zustellung von Nachrichten verwendet. Die Nutzung von FCM unterliegt den Bedingungen von Google/Firebase.

Du kannst Pushs in den App-Einstellungen aktivieren/deaktivieren (Topic „news“). Bei Deaktivierung wird das Gerät aus dem Topic abgemeldet.

6. Empfänger / Drittlandtransfer

Bei Nutzung von FCM und beim Laden von Inhalten (z. B. Coverbildern) können Anfragen an Server von Google/Firebase und Spotify gehen. Dabei ist ein Transfer in Drittländer möglich. Es gelten die jeweiligen Datenschutzbedingungen der Anbieter.

7. Speicherdauer

Favoriten verbleiben lokal, bis sie gelöscht werden. FCM-Token werden von Firebase verwaltet und können sich ändern.
